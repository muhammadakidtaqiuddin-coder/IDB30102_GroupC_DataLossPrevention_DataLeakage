# 📁 05_Data_or_Sample_Input/

This folder contains all **synthetic** input data used to train and test the prototype. No real, confidential, or organizational data is used anywhere in this repository (see the "Data and Ethical Note" section of the top-level README).

## Contents

| File | Rows | Columns | Description |
|---|---|---|---|
| `sample_documents.csv` | 30 data rows | `text`, `label` | Synthetic labeled documents used to train/test `content_classifier.py`. `label` is one of **Restricted**, **Internal**, or **Unrestricted**. |
| `sample_activity_log.csv` | 21 data rows | `user`, `day`, `files_transferred`, `volume_mb`, `destination` | Synthetic daily transfer activity per user, used by `anomaly_detector.py` to build each user's baseline transfer-volume mean/std for z-score comparison. |
| `evaluation_events.csv` | 150 data rows | `event_id`, `user`, `true_label`, `text`, `destination`, `volume_mb`, `is_spike_injected`, `ground_truth_leak` | Generated by `generate_evaluation_dataset.py`. A labeled synthetic evaluation set combining content sensitivity, destination, and volume-spike signals with an independently derived `ground_truth_leak` flag, used by `evaluate_hybrid_model.py` for RO3. |

## Relationship to Source Code

These files are the inputs consumed by the scripts in `04_Source_Code/`. Note that those scripts currently look for this data under a relative path named `data/` rather than `05_Data_or_Sample_Input/` — see the **Known Issues** section of `04_Source_Code/README.md` for the fix needed before running them as-is.

## Regenerating the Evaluation Set

`evaluation_events.csv` is not hand-written — it's generated deterministically (`random.seed(42)`) by `04_Source_Code/generate_evaluation_dataset.py` from `sample_documents.csv` and `sample_activity_log.csv`. Re-run that script if either source file changes.
